Awesome Agent Workflows

AI কোডিং এজেন্টের সাথে কাজ করার পুনরাবৃত্তিযোগ্য উপায়: পরিকল্পনা ও স্পেক, টাস্ক কিউ, পুনর্ব্যবহারযোগ্য প্রম্পট ও স্কিল, রিভিউ চেকপয়েন্ট এবং এমন ধাপ যা একজন মানুষের অপেক্ষায় থাকে।

এটি ইংরেজি সংস্করণের অনুবাদ। টুল ও ওয়েবসাইটের নাম মূল ভাষায় রাখা হয়েছে।

সূচিপত্র

নীতি ও নির্দেশিকা নির্দেশ ফাইল ও মানদণ্ড পরিকল্পনা ও স্পেক-ভিত্তিক ডেভেলপমেন্ট এজেন্টের জন্য টাস্ক ট্র্যাকিং পুনর্ব্যবহারযোগ্য প্রম্পট, স্কিল ও সাবএজেন্ট রিভিউ ও অনুমোদন পাশাপাশি এজেন্ট চালানো CI-তে এজেন্ট যে ফ্রেমওয়ার্কে মানুষ যুক্ত থাকে সম্পর্কিত তালিকা

AI কোডিং এজেন্টের সাথে কাজ করার পুনরাবৃত্তিযোগ্য উপায়: পরিকল্পনা ও স্পেক, টাস্ক কিউ, পুনর্ব্যবহারযোগ্য প্রম্পট ও স্কিল, রিভিউ চেকপয়েন্ট এবং এমন ধাপ যা একজন মানুষের অপেক্ষায় থাকে।

বিশেষ: Aubergine - ব্রাউজারে ক্যানভাসের ওপর টার্মিনাল, এমন ওয়ার্কফ্লোসহ যার ধাপ মালিকের অনুমোদনের অপেক্ষা করতে পারে, একটি টাস্ক কিউ এবং ব্যবহারের আগে রিভিউ করা ড্রাফট। (এই তালিকার মালিকদের তৈরি।)

এই তালিকা এজেন্ট নিয়ে নয়, বরং এজেন্টের চারপাশের কাজ নিয়ে: একটি কাজ কীভাবে লেখা হয়, ভাগ করা হয়, হস্তান্তর করা হয়, যাচাই ও অনুমোদন করা হয়। আলাদা করে উল্লেখ না থাকলে সব এন্ট্রি ওপেন সোর্স বা বিনামূল্যে পড়া যায়।

সূচিপত্র

  • নীতি ও নির্দেশিকা
  • নির্দেশ ফাইল ও মানদণ্ড
  • পরিকল্পনা ও স্পেক-ভিত্তিক ডেভেলপমেন্ট
  • এজেন্টের জন্য টাস্ক ট্র্যাকিং
  • পুনর্ব্যবহারযোগ্য প্রম্পট, স্কিল ও সাবএজেন্ট
  • রিভিউ ও অনুমোদন
  • পাশাপাশি এজেন্ট চালানো
  • CI-তে এজেন্ট
  • যে ফ্রেমওয়ার্কে মানুষ যুক্ত থাকে
  • সম্পর্কিত তালিকা

নীতি ও নির্দেশিকা

  • কার্যকর এজেন্ট তৈরি - ওয়ার্কফ্লো ও এজেন্টের জন্য Anthropic-এর প্যাটার্ন, প্রম্পট চেইনিং থেকে অর্কেস্ট্রেটর ও ওয়ার্কার পর্যন্ত।
  • Claude Code-এর সেরা চর্চা - অনুসন্ধান, পরিকল্পনা, কোড ও commit, এমন চেকপয়েন্টসহ যেখানে মানুষ ঢুকতে পারে।
  • 12-Factor Agents - প্রোডাকশনে চালানোর মতো নির্ভরযোগ্য এজেন্টের নীতি, যার মধ্যে মানুষের সাথে যোগাযোগকে টুল কল হিসেবে ধরা অন্তর্ভুক্ত।

নির্দেশ ফাইল ও মানদণ্ড

  • AGENTS.md - রিপোজিটরিতে একটি সাধারণ Markdown ফাইল, যা যেকোনো কোডিং এজেন্টকে বিল্ড, টেস্ট ও নিয়ম মানার উপায় বলে দেয়।
  • Model Context Protocol - এজেন্টদের টুল ও প্রসঙ্গ দেওয়ার উন্মুক্ত প্রোটোকল, সঙ্গে এর স্পেসিফিকেশন.
  • Agent Skills - নির্দেশনা ও স্ক্রিপ্টের ফোল্ডার, যা দরকার হলে এজেন্ট লোড করে।
  • Claude Code hooks - এজেন্টের পালার নির্দিষ্ট সময়ে চলা কমান্ড, এমন যাচাইয়ের জন্য যা মডেলের মনে রাখার ওপর নির্ভর করা উচিত নয়।

পরিকল্পনা ও স্পেক-ভিত্তিক ডেভেলপমেন্ট

  • Spec Kit - এজেন্ট কোড লেখার আগে স্পেক, পরিকল্পনা ও টাস্ক লেখার জন্য GitHub-এর টুলকিট।
  • OpenSpec - স্পেক-ভিত্তিক ডেভেলপমেন্ট, যেখানে প্রতিটি পরিবর্তন রিপোজিটরির ফাইল হিসেবে প্রস্তাব, রিভিউ ও সংরক্ষণ করা হয়।
  • BMAD Method - অ্যানালিস্ট ও আর্কিটেক্ট থেকে ডেভেলপার ও QA পর্যন্ত, এজেন্টদের পালন করা অ্যাজাইল ভূমিকা।
  • Agent OS - কোডবেসের মানদণ্ড ও স্পেক এমন ফাইলে লেখে যা দেখে এজেন্টরা কাজ করে।
  • Superpowers - একটি স্কিল লাইব্রেরি যা এজেন্টকে ব্রেইনস্টর্মিং, পরিকল্পনা, টেস্ট-ড্রিভেন ডেভেলপমেন্ট ও রিভিউয়ের মধ্য দিয়ে নিয়ে যায়।

এজেন্টের জন্য টাস্ক ট্র্যাকিং

  • Task Master - প্রোডাক্ট ডকুমেন্টকে পরস্পর নির্ভর টাস্কে ভাগ করে, যা এজেন্ট একে একে শেষ করে।
  • Beads - রিপোজিটরিতে রাখা একটি ইস্যু ট্র্যাকার, এজেন্টদের কাজ খোলা, নেওয়া ও বন্ধ করার জন্য তৈরি।
  • Backlog.md - Git-এ একটি Markdown টাস্ক বোর্ড, যা মানুষ ও এজেন্ট মিলে ব্যবহার করে।

পুনর্ব্যবহারযোগ্য প্রম্পট, স্কিল ও সাবএজেন্ট

  • Awesome Copilot - GitHub Copilot-এর জন্য কমিউনিটির নির্দেশনা, প্রম্পট, এজেন্ট ও স্কিল।
  • Awesome CursorRules - ভাষা ও ফ্রেমওয়ার্ক অনুযায়ী সাজানো Cursor-এর রুল ফাইল।
  • Agents by wshobson - একবার Markdown-এ লেখা প্লাগইন, সাবএজেন্ট ও কমান্ড, যা একাধিক কোডিং এজেন্টের জন্য তৈরি হয়।
  • Awesome Claude Code Subagents - শতাধিক বিশেষায়িত সাবএজেন্টের সংজ্ঞা।
  • Claude Cookbooks - প্যাটার্নের নোটবুক, এজেন্ট ওয়ার্কফ্লো ও টুল ব্যবহারসহ।

রিভিউ ও অনুমোদন

  • HumanLayer - কঠিন সমস্যায় কোডিং এজেন্টের ওয়ার্কফ্লো, যেখানে গবেষণা, পরিকল্পনা ও বাস্তবায়নের ধাপ মানুষ রিভিউ করে।
  • PR-Agent - একটি ওপেন সোর্স রিভিউয়ার যা pull request-এ মন্তব্য করে, মানুষের রিভিউয়ের পাশে দ্বিতীয় যাচাই।
  • Claude Code Security Review - একটি GitHub Action যা প্রতিটি পরিবর্তনে নিরাপত্তা সমস্যা খোঁজে।

পাশাপাশি এজেন্ট চালানো

  • Claude Squad - একসাথে কয়েকটি টার্মিনাল এজেন্ট, প্রত্যেকে নিজের Git worktree-তে, একটি টার্মিনাল থেকে পরিচালিত।
  • Container Use - প্রতিটি এজেন্টের জন্য একটি কন্টেইনার ও একটি ব্রাঞ্চ, যাতে একাধিক এজেন্ট সংঘর্ষ ছাড়াই এক প্রজেক্টে কাজ করতে পারে।
  • Crystal - worktree-তে সমান্তরাল এজেন্ট সেশনের ডেস্কটপ অ্যাপ, পদ্ধতি তুলনার জন্য (এখন Nimbalyst)।
  • Ruflo - Claude Code ও অন্যান্য এজেন্ট ঘিরে শেয়ার্ড মেমরির এজেন্ট দলকে সমন্বয় করে।

CI-তে এজেন্ট

  • Claude Code Action - GitHub Actions-এ issue ও pull request থেকে Claude Code চালায়।
  • OpenHands - কোডিং এজেন্টের জন্য উন্মুক্ত প্ল্যাটফর্ম, যা লোকালি, ক্লাউডে বা CI-তে ইন্টারফেস ছাড়া চলে।
  • SWE-agent - একটি GitHub issue নিয়ে আপনার পছন্দের ভাষা মডেল দিয়ে সমাধানের চেষ্টা করে।

যে ফ্রেমওয়ার্কে মানুষ যুক্ত থাকে

  • LangGraph - গ্রাফ হিসেবে এজেন্ট, যা একজন মানুষের জন্য থেমে থাকতে পারে এবং সংরক্ষিত অবস্থা থেকে আবার চালু হতে পারে।
  • OpenAI Agents SDK - হ্যান্ডঅফ ও গার্ডরেলসহ মাল্টি-এজেন্ট ওয়ার্কফ্লোর ছোট ফ্রেমওয়ার্ক।
  • CrewAI - ভূমিকা পালনকারী এজেন্টদের পরিচালনা করে, এমন টাস্কসহ যা মানুষের কাছে ইনপুট চাইতে পারে।

সম্পর্কিত তালিকা

  • Awesome Claude Code - Claude Code-এর জন্য স্কিল, হুক, কমান্ড ও টুল।
