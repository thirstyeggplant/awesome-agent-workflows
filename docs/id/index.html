Prinsip dan panduan

  • Membangun agen yang efektif - Pola dari Anthropic untuk alur kerja dan agen, dari rantai prompt hingga orkestrator dan pekerja.
  • Praktik terbaik Claude Code - Jelajahi, rencanakan, tulis kode, dan commit, dengan titik periksa tempat manusia bisa masuk.
  • 12-Factor Agents - Prinsip agar agen cukup andal untuk produksi, termasuk menghubungi manusia sebagai pemanggilan alat.

File instruksi dan standar

  • AGENTS.md - File Markdown biasa di repositori yang memberi tahu agen coding mana pun cara build, menguji, dan mengikuti konvensinya.
  • Model Context Protocol - Protokol terbuka untuk memberi agen alat dan konteks, beserta spesifikasi.
  • Agent Skills - Folder berisi instruksi dan skrip yang dimuat agen saat tugas membutuhkannya.
  • Claude Code hooks - Perintah yang berjalan di titik tetap giliran agen, untuk pemeriksaan yang tidak boleh bergantung pada ingatan model.

Perencanaan dan pengembangan berbasis spesifikasi

  • Spec Kit - Toolkit GitHub untuk menulis spesifikasi, rencana, dan tugas sebelum agen menulis kode.
  • OpenSpec - Pengembangan berbasis spesifikasi: setiap perubahan diusulkan, ditinjau, dan diarsipkan sebagai file di repositori.
  • BMAD Method - Peran agile yang dijalankan agen, dari analis dan arsitek hingga developer dan QA.
  • Agent OS - Menuliskan standar dan spesifikasi codebase ke file yang menjadi acuan kerja agen.
  • Superpowers - Pustaka skill yang memandu agen melalui curah gagasan, perencanaan, TDD, dan tinjauan.

Pelacakan tugas untuk agen

  • Task Master - Mengubah dokumen produk menjadi tugas-tugas yang saling bergantung untuk dikerjakan agen satu per satu.
  • Beads - Pelacak isu di dalam repositori, dibuat agar agen bisa membuat, mengambil, dan menutup pekerjaan.
  • Backlog.md - Papan tugas Markdown di Git yang dipakai bersama oleh manusia dan agen.

Prompt, skill, dan subagen yang bisa dipakai ulang

  • Awesome Copilot - Instruksi, prompt, agen, dan skill komunitas untuk GitHub Copilot.
  • Awesome CursorRules - File aturan untuk Cursor, dikelompokkan per bahasa dan framework.
  • Agents by wshobson - Plugin, subagen, dan perintah yang ditulis sekali dalam Markdown lalu dibuat untuk beberapa agen coding.
  • Awesome Claude Code Subagents - Lebih dari seratus definisi subagen khusus.
  • Claude Cookbooks - Notebook berisi pola, termasuk alur kerja agen dan penggunaan alat.

Tinjauan dan persetujuan

  • HumanLayer - Alur kerja untuk agen coding pada masalah sulit, dengan langkah riset, rencana, dan implementasi yang ditinjau manusia.
  • PR-Agent - Peninjau open source yang mengomentari pull request, sebagai pemeriksaan kedua di samping tinjauan manusia.
  • Claude Code Security Review - GitHub Action yang meninjau setiap perubahan untuk mencari masalah keamanan.

Menjalankan agen berdampingan

  • Claude Squad - Beberapa agen terminal sekaligus, masing-masing di Git worktree sendiri, dikelola dari satu terminal.
  • Container Use - Satu kontainer dan satu branch per agen, agar beberapa agen bisa mengerjakan satu proyek tanpa bentrok.
  • Crystal - Aplikasi desktop untuk sesi agen paralel di worktree, guna membandingkan pendekatan (kini Nimbalyst).
  • Ruflo - Mengoordinasikan kawanan agen dengan memori bersama di sekitar Claude Code dan agen lain.

Agen di CI

  • Claude Code Action - Menjalankan Claude Code dari issue dan pull request di GitHub Actions.
  • OpenHands - Platform terbuka untuk agen coding yang berjalan lokal, di cloud, atau tanpa antarmuka di CI.
  • SWE-agent - Mengambil issue GitHub dan mencoba memperbaikinya dengan model bahasa pilihan Anda.

Framework dengan manusia dalam alur

  • LangGraph - Agen berbentuk graf yang bisa berhenti sejenak untuk manusia lalu melanjutkan dari keadaan tersimpan.
  • OpenAI Agents SDK - Framework kecil untuk alur kerja multi-agen dengan serah terima dan pembatas.
  • CrewAI - Mengatur agen yang menjalankan peran, dengan tugas yang bisa meminta masukan dari manusia.
