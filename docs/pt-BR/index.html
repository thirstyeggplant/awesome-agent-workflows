Formas repetíveis de trabalhar com agentes de programação com IA: planos e especificações, filas de tarefas, prompts e skills reutilizáveis, pontos de revisão e etapas que esperam por uma pessoa.

Esta lista trata do trabalho em volta de um agente, e não do agente em si: como uma tarefa é escrita, dividida, entregue, conferida e aprovada. Os itens são open source ou de leitura livre, salvo indicação em contrário.

Destaque

  • Aubergine - Terminais em uma tela no navegador, com fluxos cujas etapas podem esperar a aprovação do dono, uma fila de tarefas e rascunhos revisados antes do uso. (Mantido pelos donos desta lista.)

Princípios e guias

  • Como construir agentes eficazes - Os padrões da Anthropic para fluxos e agentes, do encadeamento de prompts a orquestrador e trabalhadores.
  • Boas práticas do Claude Code - Explorar, planejar, programar e fazer commit, com pontos de controle em que uma pessoa pode intervir.
  • 12-Factor Agents - Princípios para agentes confiáveis o bastante para produção, incluindo contatar pessoas como uma chamada de ferramenta.

Arquivos de instruções e padrões

  • AGENTS.md - Um arquivo Markdown simples no repositório que diz a qualquer agente de programação como compilar, testar e seguir as convenções.
  • Model Context Protocol - O protocolo aberto para dar ferramentas e contexto aos agentes, com sua especificação.
  • Agent Skills - Pastas de instruções e scripts que um agente carrega quando a tarefa pede.
  • Claude Code hooks - Comandos que rodam em pontos fixos do turno de um agente, para verificações que não devem depender da memória do modelo.

Planejamento e desenvolvimento guiado por especificações

  • Spec Kit - O kit do GitHub para escrever uma especificação, um plano e tarefas antes de um agente escrever código.
  • OpenSpec - Desenvolvimento guiado por especificações em que cada mudança é proposta, revisada e arquivada como arquivos no repositório.
  • BMAD Method - Papéis ágeis desempenhados por agentes, de analista e arquiteto a desenvolvedor e QA.
  • Agent OS - Registra os padrões e especificações de uma base de código em arquivos usados pelos agentes.
  • Superpowers - Uma biblioteca de skills que conduz o agente por brainstorming, planejamento, TDD e revisão.

Acompanhamento de tarefas para agentes

  • Task Master - Transforma um documento de produto em tarefas dependentes que o agente resolve uma por vez.
  • Beads - Um rastreador de issues dentro do repositório, feito para agentes abrirem, assumirem e fecharem trabalho.
  • Backlog.md - Um quadro de tarefas em Markdown no Git, compartilhado por pessoas e agentes.

Prompts, skills e subagentes reutilizáveis

  • Awesome Copilot - Instruções, prompts, agentes e skills da comunidade para o GitHub Copilot.
  • Awesome CursorRules - Arquivos de regras para o Cursor, organizados por linguagem e framework.
  • Agents by wshobson - Plugins, subagentes e comandos escritos uma vez em Markdown e gerados para vários agentes de programação.
  • Awesome Claude Code Subagents - Mais de cem definições de subagentes especializados.
  • Claude Cookbooks - Notebooks com padrões, incluindo fluxos de agentes e uso de ferramentas.

Revisão e aprovação

  • HumanLayer - Fluxos para agentes de programação em problemas difíceis, com etapas de pesquisa, plano e implementação revisadas por uma pessoa.
  • PR-Agent - Um revisor open source que comenta pull requests, uma segunda passada ao lado da revisão humana.
  • Claude Code Security Review - Uma GitHub Action que revisa cada mudança em busca de problemas de segurança.

Agentes lado a lado

  • Claude Squad - Vários agentes de terminal ao mesmo tempo, cada um em seu próprio worktree do Git, gerenciados a partir de um terminal.
  • Container Use - Um contêiner e um branch por agente, para que vários trabalhem no mesmo projeto sem conflito.
  • Crystal - Um app de desktop para sessões paralelas de agentes em worktrees, para comparar abordagens (agora Nimbalyst).
  • Ruflo - Coordena enxames de agentes com memória compartilhada em torno do Claude Code e de outros agentes.

Agentes em CI

  • Claude Code Action - Executa o Claude Code a partir de issues e pull requests no GitHub Actions.
  • OpenHands - Uma plataforma aberta para agentes de programação que roda localmente, na nuvem ou sem interface em CI.
  • SWE-agent - Pega uma issue do GitHub e tenta corrigi-la, com o modelo de linguagem que você escolher.

Frameworks com uma pessoa no circuito

  • LangGraph - Agentes como grafos que podem pausar para uma pessoa e retomar de um estado salvo.
  • OpenAI Agents SDK - Um framework enxuto para fluxos multiagente com repasses e salvaguardas.
  • CrewAI - Orquestra agentes que desempenham papéis, com tarefas que podem pedir informações a uma pessoa.
