与 AI 编程智能体协作的可复用方法：计划与规格、任务队列、可复用的提示词和技能、评审检查点，以及等待人工确认的步骤。

本列表关注的是智能体周围的工作，而不是智能体本身：任务如何被写下、拆分、移交、检查和批准。除非另有说明，条目均为开源或可免费阅读。

精选推荐

  • Aubergine - 浏览器画布上的终端，带有可等待所有者批准的工作流步骤、任务队列，以及使用前需审阅的草稿。（由本列表的维护者开发。）

原则与指南

  • 构建高效的智能体 - Anthropic 总结的工作流与智能体模式，从提示词链到编排者与执行者。
  • Claude Code 最佳实践 - 探索、规划、编码、提交，并设有人可以介入的检查点。
  • 12-Factor Agents - 让智能体足以用于生产环境的原则，包括把联系人工作为一次工具调用。

指令文件与标准

  • AGENTS.md - 仓库中的一个普通 Markdown 文件，告诉任何编程智能体如何构建、测试并遵循项目约定。
  • Model Context Protocol - 为智能体提供工具和上下文的开放协议，另见其 规范.
  • Agent Skills - 由指令和脚本组成的文件夹，智能体在任务需要时加载。
  • Claude Code hooks - 在智能体回合的固定时刻运行的命令，用于不应依赖模型记忆的检查。

规划与规格驱动开发

  • Spec Kit - GitHub 的工具包，在智能体写代码之前先写好规格、计划和任务。
  • OpenSpec - 规格驱动开发：每个变更都以仓库中的文件形式提出、评审和归档。
  • BMAD Method - 由智能体扮演的敏捷角色，从分析师、架构师到开发者和测试。
  • Agent OS - 把代码库的标准和规格写成智能体可依据的文件。
  • Superpowers - 一个技能库，引导智能体完成头脑风暴、规划、测试驱动开发和评审。

面向智能体的任务跟踪

  • Task Master - 把产品文档拆成有依赖关系的任务，让智能体逐个完成。
  • Beads - 存放在仓库中的问题跟踪器，专为智能体创建、领取和关闭任务而设计。
  • Backlog.md - 放在 Git 中、由人和智能体共享的 Markdown 任务看板。

可复用的提示词、技能和子智能体

  • Awesome Copilot - 面向 GitHub Copilot 的社区指令、提示词、智能体和技能。
  • Awesome CursorRules - Cursor 规则文件，按语言和框架分类。
  • Agents by wshobson - 用 Markdown 编写一次即可为多个编程智能体生成的插件、子智能体和命令。
  • Awesome Claude Code Subagents - 一百多个专业子智能体定义。
  • Claude Cookbooks - 收录各种模式的笔记本，包括智能体工作流和工具调用。

评审与批准

  • HumanLayer - 面向难题的编程智能体工作流，包含由人评审的调研、规划和实现步骤。
  • PR-Agent - 一个开源的代码评审工具，会在 pull request 上发表评论，作为人工评审之外的第二道把关。
  • Claude Code Security Review - 一个检查每次变更安全问题的 GitHub Action。

并行运行智能体

  • Claude Squad - 同时运行多个终端智能体，各自位于独立的 Git worktree，并在一个终端中统一管理。
  • Container Use - 每个智能体一个容器和一个分支，让多个智能体在同一项目中互不干扰。
  • Crystal - 在 worktree 中并行运行智能体会话的桌面应用，便于比较不同方案（现名 Nimbalyst）。
  • Ruflo - 围绕 Claude Code 等智能体，协调共享记忆的智能体集群。

CI 中的智能体

  • Claude Code Action - 在 GitHub Actions 中通过 issue 和 pull request 运行 Claude Code。
  • OpenHands - 开放的编程智能体平台，可在本地、云端或 CI 中无界面运行。
  • SWE-agent - 接收一个 GitHub issue 并尝试修复，可使用你选择的语言模型。

有人参与环节的框架

  • LangGraph - 以图的形式构建智能体，可以 暂停等待人工 并从保存的状态继续运行。
  • OpenAI Agents SDK - 一个支持交接和防护机制的轻量多智能体工作流框架。
  • CrewAI - 编排扮演不同角色的智能体，任务可以向人请求输入。
