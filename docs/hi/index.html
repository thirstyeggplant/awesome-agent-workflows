Awesome Agent Workflows

AI कोडिंग एजेंटों के साथ काम करने के दोहराए जा सकने वाले तरीके: योजना और स्पेक, टास्क कतारें, दोबारा इस्तेमाल होने वाले प्रॉम्प्ट और स्किल, समीक्षा पड़ाव और ऐसे चरण जो किसी व्यक्ति का इंतज़ार करते हैं।

यह अंग्रेज़ी संस्करण का अनुवाद है। टूल और वेबसाइटों के नाम मूल रूप में रखे गए हैं।

विषय-सूची

विशेष सिद्धांत और गाइड निर्देश फ़ाइलें और मानक योजना और स्पेक-आधारित डेवलपमेंट एजेंटों के लिए टास्क ट्रैकिंग दोबारा उपयोग होने वाले प्रॉम्प्ट, स्किल और सबएजेंट समीक्षा और मंज़ूरी एजेंटों को साथ-साथ चलाना CI में एजेंट जिन फ़्रेमवर्क में इंसान शामिल रहता है संबंधित सूचियाँ

AI कोडिंग एजेंटों के साथ काम करने के दोहराए जा सकने वाले तरीके: योजना और स्पेक, टास्क कतारें, दोबारा इस्तेमाल होने वाले प्रॉम्प्ट और स्किल, समीक्षा पड़ाव और ऐसे चरण जो किसी व्यक्ति का इंतज़ार करते हैं।

यह सूची एजेंट के बारे में कम और उसके आसपास के काम के बारे में ज़्यादा है: कोई काम कैसे लिखा जाता है, बाँटा जाता है, सौंपा जाता है, जाँचा जाता है और मंज़ूर होता है। जब तक अलग से न लिखा हो, प्रविष्टियाँ ओपन सोर्स हैं या मुफ़्त में पढ़ी जा सकती हैं।

विशेष

  • Aubergine - ब्राउज़र में कैनवास पर टर्मिनल, ऐसे वर्कफ़्लो के साथ जिनके चरण मालिक की मंज़ूरी का इंतज़ार कर सकते हैं, एक टास्क कतार और इस्तेमाल से पहले जाँचे जाने वाले ड्राफ़्ट। (इस सूची के मालिकों द्वारा बनाया गया।)

सिद्धांत और गाइड

  • असरदार एजेंट बनाना - वर्कफ़्लो और एजेंटों के लिए Anthropic के पैटर्न, प्रॉम्प्ट चेनिंग से लेकर ऑर्केस्ट्रेटर और वर्कर तक।
  • Claude Code के सर्वोत्तम तरीके - खोजें, योजना बनाएँ, कोड करें और commit करें, ऐसे पड़ावों के साथ जहाँ इंसान बीच में आ सके।
  • 12-Factor Agents - प्रोडक्शन लायक़ भरोसेमंद एजेंटों के सिद्धांत, जिनमें लोगों से संपर्क को टूल कॉल की तरह करना भी शामिल है।

निर्देश फ़ाइलें और मानक

  • AGENTS.md - रिपॉज़िटरी में एक सादी Markdown फ़ाइल, जो किसी भी कोडिंग एजेंट को बताती है कि बिल्ड, टेस्ट कैसे करें और नियमों का पालन कैसे करें।
  • Model Context Protocol - एजेंटों को टूल और संदर्भ देने का खुला प्रोटोकॉल, साथ में इसका विनिर्देश.
  • Agent Skills - निर्देशों और स्क्रिप्ट के फ़ोल्डर, जिन्हें एजेंट ज़रूरत पड़ने पर लोड करता है।
  • Claude Code hooks - एजेंट की बारी के तय बिंदुओं पर चलने वाले कमांड, उन जाँचों के लिए जो मॉडल की याददाश्त पर निर्भर नहीं होनी चाहिए।

योजना और स्पेक-आधारित डेवलपमेंट

  • Spec Kit - एजेंट के कोड लिखने से पहले स्पेक, योजना और टास्क लिखने के लिए GitHub का टूलकिट।
  • OpenSpec - स्पेक-आधारित डेवलपमेंट, जिसमें हर बदलाव रिपॉज़िटरी में फ़ाइलों के रूप में प्रस्तावित, समीक्षित और संग्रहित होता है।
  • BMAD Method - एजेंटों द्वारा निभाई जाने वाली एजाइल भूमिकाएँ, एनालिस्ट और आर्किटेक्ट से लेकर डेवलपर और QA तक।
  • Agent OS - कोडबेस के मानकों और स्पेक को ऐसी फ़ाइलों में लिखता है जिनसे एजेंट काम करते हैं।
  • Superpowers - एक स्किल लाइब्रेरी जो एजेंट को विचार-मंथन, योजना, टेस्ट-ड्रिवन डेवलपमेंट और समीक्षा से गुज़ारती है।

एजेंटों के लिए टास्क ट्रैकिंग

  • Task Master - प्रोडक्ट दस्तावेज़ को आपस में जुड़े टास्क में बदलता है, जिन्हें एजेंट एक-एक करके पूरा करता है।
  • Beads - रिपॉज़िटरी में रखा इश्यू ट्रैकर, जो एजेंटों के लिए काम दर्ज करने, उठाने और बंद करने के लिए बना है।
  • Backlog.md - Git में एक Markdown टास्क बोर्ड, जिसे लोग और एजेंट साझा करते हैं।

दोबारा उपयोग होने वाले प्रॉम्प्ट, स्किल और सबएजेंट

  • Awesome Copilot - GitHub Copilot के लिए समुदाय के निर्देश, प्रॉम्प्ट, एजेंट और स्किल।
  • Awesome CursorRules - Cursor के लिए नियम फ़ाइलें, भाषा और फ़्रेमवर्क के अनुसार।
  • Agents by wshobson - प्लगइन, सबएजेंट और कमांड जो एक बार Markdown में लिखे जाते हैं और कई कोडिंग एजेंटों के लिए बनाए जाते हैं।
  • Awesome Claude Code Subagents - सौ से ज़्यादा विशेष सबएजेंट परिभाषाएँ।
  • Claude Cookbooks - पैटर्न वाली नोटबुक, जिनमें एजेंट वर्कफ़्लो और टूल का उपयोग शामिल है।

समीक्षा और मंज़ूरी

  • HumanLayer - कठिन समस्याओं पर कोडिंग एजेंटों के वर्कफ़्लो, जिनमें शोध, योजना और कार्यान्वयन के चरणों की समीक्षा इंसान करता है।
  • PR-Agent - एक ओपन सोर्स रिव्यूअर जो pull request पर टिप्पणी करता है, इंसानी समीक्षा के साथ दूसरी जाँच।
  • Claude Code Security Review - एक GitHub Action जो हर बदलाव में सुरक्षा समस्याएँ जाँचता है।

एजेंटों को साथ-साथ चलाना

  • Claude Squad - एक साथ कई टर्मिनल एजेंट, हर एक अपने Git worktree में, एक ही टर्मिनल से संभाले जाते हैं।
  • Container Use - हर एजेंट के लिए एक कंटेनर और एक ब्रांच, ताकि कई एजेंट बिना टकराए एक प्रोजेक्ट पर काम करें।
  • Crystal - worktree में समानांतर एजेंट सत्रों के लिए डेस्कटॉप ऐप, तरीकों की तुलना के लिए (अब Nimbalyst)।
  • Ruflo - Claude Code और दूसरे एजेंटों के इर्द-गिर्द साझा मेमोरी वाले एजेंट झुंडों का तालमेल करता है।

CI में एजेंट

  • Claude Code Action - GitHub Actions में issue और pull request से Claude Code चलाता है।
  • OpenHands - कोडिंग एजेंटों के लिए खुला प्लेटफ़ॉर्म जो लोकल, क्लाउड में या CI में बिना इंटरफ़ेस के चलता है।
  • SWE-agent - GitHub issue लेकर आपके चुने हुए भाषा मॉडल से उसे ठीक करने की कोशिश करता है।

जिन फ़्रेमवर्क में इंसान शामिल रहता है

  • LangGraph - ग्राफ़ के रूप में एजेंट, जो किसी व्यक्ति के लिए रुक सकते हैं और सहेजी गई स्थिति से फिर शुरू हो सकते हैं।
  • OpenAI Agents SDK - हैंडऑफ़ और गार्डरेल वाले मल्टी-एजेंट वर्कफ़्लो के लिए छोटा फ़्रेमवर्क।
  • CrewAI - भूमिकाएँ निभाने वाले एजेंटों का संचालन करता है, ऐसे टास्क के साथ जो इंसान से इनपुट माँग सकते हैं।

संबंधित सूचियाँ
