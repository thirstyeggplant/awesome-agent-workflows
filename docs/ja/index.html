AI コーディングエージェントと働くための再現可能な方法：計画と仕様、タスクキュー、再利用できるプロンプトとスキル、レビューの関門、そして人を待つステップ。

このリストが扱うのはエージェントそのものではなく、その周りの仕事です。タスクをどう書き、分割し、引き渡し、確認し、承認するか。特に記載がない限り、項目はオープンソースか自由に読めるものです。

注目

  • Aubergine - ブラウザのキャンバス上のターミナル。オーナーの承認を待てるステップを持つワークフロー、タスクキュー、使う前にレビューする下書きを備えています。（このリストの管理者が開発しています。）

原則とガイド

  • 効果的なエージェントの作り方 - プロンプトチェーンからオーケストレーターとワーカーまで、Anthropic によるワークフローとエージェントのパターン。
  • Claude Code のベストプラクティス - 調べる、計画する、書く、コミットする。人が介入できるチェックポイント付き。
  • 12-Factor Agents - 本番運用に耐えるエージェントのための原則。人への連絡をツール呼び出しとして扱うことも含みます。

指示ファイルと標準

  • AGENTS.md - リポジトリに置くただの Markdown ファイルで、どのコーディングエージェントにもビルド、テスト、規約の守り方を伝えます。
  • Model Context Protocol - エージェントにツールとコンテキストを与えるためのオープンプロトコル。こちらは 仕様.
  • Agent Skills - タスクが必要とするときにエージェントが読み込む、指示とスクリプトのフォルダ。
  • Claude Code hooks - エージェントのターンの決まった時点で実行されるコマンド。モデルの記憶に頼るべきでないチェックのために。

計画と仕様駆動開発

  • Spec Kit - エージェントがコードを書く前に、仕様、計画、タスクを書くための GitHub のツールキット。
  • OpenSpec - 各変更をリポジトリ内のファイルとして提案・レビュー・保管する仕様駆動開発。
  • BMAD Method - アナリストやアーキテクトから開発者、QA まで、アジャイルの役割をエージェントが担います。
  • Agent OS - コードベースの標準と仕様を、エージェントが参照するファイルに書き出します。
  • Superpowers - ブレインストーミング、計画、テスト駆動開発、レビューへとエージェントを導くスキルライブラリ。

エージェントのためのタスク管理

  • Task Master - プロダクト文書を依存関係のあるタスクに分解し、エージェントが 1 つずつ進めます。
  • Beads - リポジトリ内に置く課題管理ツールで、エージェントが作業を起票・着手・完了できるように作られています。
  • Backlog.md - 人とエージェントが共有する、Git 上の Markdown タスクボード。

再利用できるプロンプト、スキル、サブエージェント

  • Awesome Copilot - GitHub Copilot 向けのコミュニティ製の指示、プロンプト、エージェント、スキル。
  • Awesome CursorRules - 言語とフレームワーク別に整理した Cursor のルールファイル。
  • Agents by wshobson - Markdown で一度書くだけで、複数のコーディングエージェント向けに生成されるプラグイン、サブエージェント、コマンド。
  • Awesome Claude Code Subagents - 100 を超える専門サブエージェントの定義。
  • Claude Cookbooks - エージェントのワークフローやツール利用などのパターンを集めたノートブック。

レビューと承認

  • HumanLayer - 難しい問題に取り組むコーディングエージェントのためのワークフロー。調査、計画、実装の各ステップを人がレビューします。
  • PR-Agent - プルリクエストにコメントするオープンソースのレビュアー。人のレビューに加える二重チェックとして。
  • Claude Code Security Review - 変更ごとにセキュリティ上の問題をレビューする GitHub Action。

エージェントを並べて動かす

  • Claude Squad - 複数のターミナルエージェントを同時に、それぞれ専用の Git worktree で動かし、1 つのターミナルから管理します。
  • Container Use - エージェントごとにコンテナとブランチを用意し、複数が衝突せずに 1 つのプロジェクトで作業できます。
  • Crystal - worktree で並列にエージェントのセッションを走らせ、やり方を比べるデスクトップアプリ（現 Nimbalyst）。
  • Ruflo - Claude Code などを中心に、共有メモリを持つエージェント群を協調させます。

CI のエージェント

  • Claude Code Action - GitHub Actions で issue やプルリクエストから Claude Code を実行します。
  • OpenHands - ローカル、クラウド、または CI でヘッドレスに動く、コーディングエージェントのためのオープンなプラットフォーム。
  • SWE-agent - 好きな言語モデルを使って、GitHub の issue を受け取り修正を試みます。

人が介在するフレームワーク

  • LangGraph - グラフとして構成したエージェントで、 人のために一時停止 し、保存した状態から再開できます。
  • OpenAI Agents SDK - 引き継ぎとガードレールを備えた、マルチエージェントワークフローのための小さなフレームワーク。
  • CrewAI - 役割を持つエージェントを編成し、タスクから人に入力を求めることもできます。
