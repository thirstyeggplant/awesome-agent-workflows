Awesome Agent Workflows

طرق قابلة للتكرار للعمل مع وكلاء البرمجة بالذكاء الاصطناعي: خطط ومواصفات، وطوابير مهام، وأوامر ومهارات قابلة لإعادة الاستخدام، ونقاط مراجعة، وخطوات تنتظر إنسانًا.

هذه ترجمة للنسخة الإنجليزية. أُبقيت أسماء الأدوات والمواقع بلغتها الأصلية.

المحتويات

مميّز مبادئ وأدلة ملفات التعليمات والمعايير التخطيط والتطوير القائم على المواصفات تتبّع المهام للوكلاء أوامر ومهارات ووكلاء فرعيون قابلة لإعادة الاستخدام المراجعة والاعتماد تشغيل الوكلاء جنبًا إلى جنب الوكلاء في التكامل المستمر أطر عمل يشارك فيها إنسان قوائم ذات صلة

طرق قابلة للتكرار للعمل مع وكلاء البرمجة بالذكاء الاصطناعي: خطط ومواصفات، وطوابير مهام، وأوامر ومهارات قابلة لإعادة الاستخدام، ونقاط مراجعة، وخطوات تنتظر إنسانًا.

تتناول هذه القائمة العمل المحيط بالوكيل لا الوكيل نفسه: كيف تُكتب المهمة وتُقسَّم وتُسلَّم وتُراجَع وتُعتمد. العناصر مفتوحة المصدر أو متاحة للقراءة مجانًا ما لم يُذكر غير ذلك.

مميّز

  • Aubergine - طرفيات على لوحة داخل المتصفح، مع مسارات عمل يمكن لخطواتها انتظار موافقة المالك، وطابور مهام، ومسودات تُراجَع قبل الاستخدام. (يطوّره القائمون على هذه القائمة.)

مبادئ وأدلة

  • بناء وكلاء فعّالين - أنماط Anthropic لمسارات العمل والوكلاء، من تسلسل الأوامر إلى المنسّق والعمّال.
  • أفضل ممارسات Claude Code - استكشف وخطّط واكتب الشيفرة ثم نفّذ commit، مع نقاط تحقق يمكن لإنسان التدخل فيها.
  • 12-Factor Agents - مبادئ لوكلاء موثوقين بما يكفي للإنتاج، منها التواصل مع البشر عبر استدعاء أداة.

ملفات التعليمات والمعايير

  • AGENTS.md - ملف Markdown بسيط في المستودع يخبر أي وكيل برمجة بكيفية البناء والاختبار واتباع أعراف المشروع.
  • Model Context Protocol - البروتوكول المفتوح لتزويد الوكلاء بالأدوات والسياق، مع المواصفة.
  • Agent Skills - مجلدات من التعليمات والسكربتات يحمّلها الوكيل عندما تتطلبها المهمة.
  • Claude Code hooks - أوامر تعمل في نقاط ثابتة من دور الوكيل، لفحوص لا ينبغي أن تعتمد على تذكّر النموذج.

التخطيط والتطوير القائم على المواصفات

  • Spec Kit - أدوات GitHub لكتابة مواصفة وخطة ومهام قبل أن يكتب الوكيل الشيفرة.
  • OpenSpec - تطوير قائم على المواصفات، يُقترح فيه كل تغيير ويُراجَع ويُؤرشف كملفات في المستودع.
  • BMAD Method - أدوار رشيقة يؤديها الوكلاء، من المحلل والمعماري إلى المطوّر ومختبر الجودة.
  • Agent OS - يدوّن معايير قاعدة الشيفرة ومواصفاتها في ملفات يعمل الوكلاء وفقها.
  • Superpowers - مكتبة مهارات ترشد الوكيل عبر العصف الذهني والتخطيط والتطوير المقاد بالاختبارات والمراجعة.

تتبّع المهام للوكلاء

  • Task Master - يحوّل وثيقة المنتج إلى مهام مترابطة ينجزها الوكيل واحدة تلو الأخرى.
  • Beads - متتبّع مشكلات محفوظ في المستودع، مصمم ليُنشئ الوكلاء العمل ويتولّوه ويغلقوه.
  • Backlog.md - لوحة مهام بصيغة Markdown داخل Git يتشاركها البشر والوكلاء.

أوامر ومهارات ووكلاء فرعيون قابلة لإعادة الاستخدام

  • Awesome Copilot - تعليمات وأوامر ووكلاء ومهارات من المجتمع لـ GitHub Copilot.
  • Awesome CursorRules - ملفات قواعد لـ Cursor مرتبة حسب اللغة وإطار العمل.
  • Agents by wshobson - إضافات ووكلاء فرعيون وأوامر تُكتب مرة واحدة بـ Markdown وتُولَّد لعدة وكلاء برمجة.
  • Awesome Claude Code Subagents - أكثر من مئة تعريف لوكلاء فرعيين متخصصين.
  • Claude Cookbooks - دفاتر أنماط، تشمل مسارات عمل الوكلاء واستخدام الأدوات.

المراجعة والاعتماد

  • HumanLayer - مسارات عمل لوكلاء البرمجة في المشكلات الصعبة، بخطوات بحث وتخطيط وتنفيذ يراجعها إنسان.
  • PR-Agent - مراجِع مفتوح المصدر يعلّق على طلبات الدمج، كفحص ثانٍ بجانب مراجعة الإنسان.
  • Claude Code Security Review - إجراء GitHub يراجع كل تغيير بحثًا عن مشكلات أمنية.

تشغيل الوكلاء جنبًا إلى جنب

  • Claude Squad - عدة وكلاء طرفية في آن واحد، لكلٍّ منهم worktree خاص في Git، تُدار من طرفية واحدة.
  • Container Use - حاوية وفرع لكل وكيل، ليعمل عدة وكلاء على مشروع واحد دون تصادم.
  • Crystal - تطبيق سطح مكتب لجلسات وكلاء متوازية في worktrees لمقارنة الأساليب (اسمه الآن Nimbalyst).
  • Ruflo - ينسّق أسرابًا من الوكلاء بذاكرة مشتركة حول Claude Code ووكلاء آخرين.

الوكلاء في التكامل المستمر

  • Claude Code Action - يشغّل Claude Code من المشكلات وطلبات الدمج في GitHub Actions.
  • OpenHands - منصة مفتوحة لوكلاء البرمجة تعمل محليًا أو في السحابة أو دون واجهة في التكامل المستمر.
  • SWE-agent - يأخذ مشكلة من GitHub ويحاول إصلاحها بنموذج اللغة الذي تختاره.

أطر عمل يشارك فيها إنسان

  • LangGraph - وكلاء على شكل رسوم بيانية يمكنها أن تتوقف مؤقتًا لإنسان ثم تستأنف من حالة محفوظة.
  • OpenAI Agents SDK - إطار عمل صغير لمسارات عمل متعددة الوكلاء مع تسليم المهام وضوابط الحماية.
  • CrewAI - ينسّق وكلاء يؤدون أدوارًا، بمهام يمكنها طلب مدخلات من إنسان.
