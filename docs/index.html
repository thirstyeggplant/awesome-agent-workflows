Repeatable ways of working with AI coding agents: plans and specs, task queues, reusable prompts and skills, review checkpoints, and steps that wait for a person.

This list is about the work around an agent rather than the agent itself: how a task is written down, broken up, handed over, checked and approved. Entries are open source or freely readable unless marked otherwise.

Featured

  • Aubergine - Terminals on a canvas in the browser, with workflows whose steps can wait for the owner's approval, a task queue and drafts reviewed before use. (Maintained by the owners of this list.)

Principles and guides

  • Building effective agents - Anthropic's patterns for workflows and agents, from prompt chaining to orchestrator and workers.
  • Claude Code best practices - Explore, plan, code and commit, with checkpoints a person can step into.
  • 12-Factor Agents - Principles for agents reliable enough for production, including contacting people as a tool call.

Instruction files and standards

  • AGENTS.md - A plain Markdown file in a repository that tells any coding agent how to build, test and follow its conventions.
  • Model Context Protocol - The open protocol for giving agents tools and context, with its specification.
  • Agent Skills - Folders of instructions and scripts that an agent loads when a task calls for them.
  • Claude Code hooks - Commands that run at fixed points of an agent's turn, for checks that should not depend on the model remembering.

Planning and spec-driven development

  • Spec Kit - GitHub's toolkit for writing a specification, a plan and tasks before an agent writes code.
  • OpenSpec - Spec-driven development where each change is proposed, reviewed and archived as files in the repository.
  • BMAD Method - Agile roles played by agents, from analyst and architect to developer and QA.
  • Agent OS - Writes a codebase's standards and specs into files agents work from.
  • Superpowers - A skills library that walks an agent through brainstorming, planning, test-driven development and review.

Task tracking for agents

  • Task Master - Turns a product document into dependent tasks that an agent works through one at a time.
  • Beads - An issue tracker kept in the repository, made for agents to file, pick up and close work.
  • Backlog.md - A Markdown task board in Git that people and agents share.

Reusable prompts, skills and subagents

  • Awesome Copilot - Community instructions, prompts, agents and skills for GitHub Copilot.
  • Awesome CursorRules - Rule files for Cursor, sorted by language and framework.
  • Agents by wshobson - Plugins, subagents and commands written once in Markdown and generated for several coding agents.
  • Awesome Claude Code Subagents - More than a hundred specialised subagent definitions.
  • Claude Cookbooks - Notebooks of patterns, including agent workflows and tool use.

Review and approval

  • HumanLayer - Workflows for coding agents on hard problems, with research, plan and implement steps a person reviews.
  • PR-Agent - An open source reviewer that comments on pull requests, a second pass beside a person's review.
  • Claude Code Security Review - A GitHub Action that reviews each change for security problems.

Running agents side by side

  • Claude Squad - Several terminal agents at once, each in its own Git worktree, managed from one terminal.
  • Container Use - A container and a branch per agent, so several can work on one project without colliding.
  • Crystal - A desktop app for parallel agent sessions in worktrees, to compare approaches (now Nimbalyst).
  • Ruflo - Coordinates swarms of agents with shared memory around Claude Code and other agents.

Agents in CI

  • Claude Code Action - Runs Claude Code from issues and pull requests in GitHub Actions.
  • OpenHands - An open platform for coding agents that runs locally, in the cloud or headless in CI.
  • SWE-agent - Takes a GitHub issue and tries to fix it, with the language model of your choice.

Frameworks with a person in the loop

  • LangGraph - Agents as graphs that can pause for a person and resume from saved state.
  • OpenAI Agents SDK - A small framework for multi-agent workflows with handoffs and guardrails.
  • CrewAI - Orchestrates agents that play roles, with tasks that can ask a person for input.

Related lists
