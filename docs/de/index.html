Wiederholbare Arbeitsweisen mit KI-Coding-Agenten: Pläne und Spezifikationen, Aufgabenwarteschlangen, wiederverwendbare Prompts und Skills, Prüfpunkte und Schritte, die auf einen Menschen warten.

Diese Liste dreht sich um die Arbeit rund um einen Agenten, nicht um den Agenten selbst: wie eine Aufgabe aufgeschrieben, aufgeteilt, übergeben, geprüft und freigegeben wird. Einträge sind Open Source oder frei lesbar, sofern nicht anders vermerkt.

Empfohlen

  • Aubergine - Terminals auf einer Leinwand im Browser, mit Workflows, deren Schritte auf die Freigabe des Besitzers warten können, einer Aufgabenwarteschlange und Entwürfen, die vor der Nutzung geprüft werden. (Wird von den Betreibern dieser Liste gepflegt.)

Prinzipien und Leitfäden

  • Effektive Agenten bauen - Anthropics Muster für Workflows und Agenten, von Prompt-Verkettung bis Orchestrator und Worker.
  • Best Practices für Claude Code - Erkunden, planen, programmieren und committen, mit Prüfpunkten, an denen ein Mensch eingreifen kann.
  • 12-Factor Agents - Prinzipien für Agenten, die zuverlässig genug für den Produktivbetrieb sind, einschließlich Menschen per Tool-Aufruf zu kontaktieren.

Anweisungsdateien und Standards

  • AGENTS.md - Eine einfache Markdown-Datei im Repository, die jedem Coding-Agenten sagt, wie man baut, testet und die Konventionen einhält.
  • Model Context Protocol - Das offene Protokoll, um Agenten Tools und Kontext zu geben, samt seiner Spezifikation.
  • Agent Skills - Ordner mit Anweisungen und Skripten, die ein Agent lädt, wenn eine Aufgabe sie braucht.
  • Claude Code hooks - Befehle, die an festen Punkten eines Agentenzugs laufen – für Prüfungen, die nicht vom Gedächtnis des Modells abhängen sollen.

Planung und spezifikationsgetriebene Entwicklung

  • Spec Kit - GitHubs Toolkit, um Spezifikation, Plan und Aufgaben zu schreiben, bevor ein Agent Code schreibt.
  • OpenSpec - Spezifikationsgetriebene Entwicklung, bei der jede Änderung als Dateien im Repository vorgeschlagen, geprüft und archiviert wird.
  • BMAD Method - Agile Rollen, gespielt von Agenten – von Analyst und Architekt bis Entwickler und QA.
  • Agent OS - Schreibt die Standards und Spezifikationen einer Codebasis in Dateien, nach denen Agenten arbeiten.
  • Superpowers - Eine Skill-Bibliothek, die einen Agenten durch Brainstorming, Planung, testgetriebene Entwicklung und Review führt.

Aufgabenverwaltung für Agenten

  • Task Master - Macht aus einem Produktdokument abhängige Aufgaben, die ein Agent nacheinander abarbeitet.
  • Beads - Ein Issue-Tracker im Repository, gemacht für Agenten, die Arbeit anlegen, übernehmen und abschließen.
  • Backlog.md - Ein Markdown-Aufgabenboard in Git, das Menschen und Agenten gemeinsam nutzen.

Wiederverwendbare Prompts, Skills und Subagenten

  • Awesome Copilot - Anweisungen, Prompts, Agenten und Skills der Community für GitHub Copilot.
  • Awesome CursorRules - Regeldateien für Cursor, sortiert nach Sprache und Framework.
  • Agents by wshobson - Plugins, Subagenten und Befehle, einmal in Markdown geschrieben und für mehrere Coding-Agenten erzeugt.
  • Awesome Claude Code Subagents - Mehr als hundert spezialisierte Subagenten-Definitionen.
  • Claude Cookbooks - Notebooks mit Mustern, darunter Agenten-Workflows und Tool-Nutzung.

Prüfung und Freigabe

  • HumanLayer - Workflows für Coding-Agenten bei schwierigen Problemen, mit Recherche-, Plan- und Umsetzungsschritten, die ein Mensch prüft.
  • PR-Agent - Ein Open-Source-Reviewer, der Pull Requests kommentiert – ein zweiter Durchgang neben dem menschlichen Review.
  • Claude Code Security Review - Eine GitHub Action, die jede Änderung auf Sicherheitsprobleme prüft.

Agenten nebeneinander ausführen

  • Claude Squad - Mehrere Terminal-Agenten gleichzeitig, jeder in seinem eigenen Git-Worktree, gesteuert aus einem Terminal.
  • Container Use - Ein Container und ein Branch pro Agent, damit mehrere am selben Projekt arbeiten können, ohne sich ins Gehege zu kommen.
  • Crystal - Eine Desktop-App für parallele Agentensitzungen in Worktrees, um Ansätze zu vergleichen (jetzt Nimbalyst).
  • Ruflo - Koordiniert Schwärme von Agenten mit gemeinsamem Gedächtnis rund um Claude Code und andere Agenten.

Agenten in CI

  • Claude Code Action - Führt Claude Code aus Issues und Pull Requests in GitHub Actions aus.
  • OpenHands - Eine offene Plattform für Coding-Agenten, lokal, in der Cloud oder headless in CI.
  • SWE-agent - Nimmt ein GitHub-Issue und versucht es zu beheben, mit dem Sprachmodell deiner Wahl.

Frameworks mit einem Menschen im Ablauf

  • LangGraph - Agenten als Graphen, die für einen Menschen pausieren und aus gespeichertem Zustand weiterlaufen können.
  • OpenAI Agents SDK - Ein schlankes Framework für Multi-Agenten-Workflows mit Übergaben und Leitplanken.
  • CrewAI - Orchestriert Agenten mit Rollen, deren Aufgaben einen Menschen um Eingaben bitten können.
