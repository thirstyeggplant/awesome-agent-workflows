Formas repetibles de trabajar con agentes de programación con IA: planes y especificaciones, colas de tareas, prompts y skills reutilizables, puntos de revisión y pasos que esperan a una persona.

Esta lista trata del trabajo alrededor de un agente más que del agente en sí: cómo se escribe una tarea, cómo se divide, se entrega, se revisa y se aprueba. Las entradas son de código abierto o de lectura libre salvo que se indique lo contrario.

Destacado

  • Aubergine - Terminales en un lienzo en el navegador, con flujos de trabajo cuyos pasos pueden esperar la aprobación del propietario, una cola de tareas y borradores revisados antes de usarse. (Mantenido por los autores de esta lista.)

Principios y guías

  • Cómo construir agentes eficaces - Los patrones de Anthropic para flujos de trabajo y agentes, desde el encadenamiento de prompts hasta orquestador y trabajadores.
  • Buenas prácticas de Claude Code - Explorar, planificar, programar y hacer commit, con puntos de control en los que puede intervenir una persona.
  • 12-Factor Agents - Principios para agentes lo bastante fiables para producción, incluido contactar a personas como una llamada a herramienta.

Archivos de instrucciones y estándares

  • AGENTS.md - Un archivo Markdown en un repositorio que explica a cualquier agente de programación cómo compilar, probar y seguir sus convenciones.
  • Model Context Protocol - El protocolo abierto para dar herramientas y contexto a los agentes, con su especificación.
  • Agent Skills - Carpetas de instrucciones y scripts que un agente carga cuando una tarea lo requiere.
  • Claude Code hooks - Comandos que se ejecutan en puntos fijos del turno de un agente, para comprobaciones que no deben depender de la memoria del modelo.

Planificación y desarrollo guiado por especificaciones

  • Spec Kit - El kit de GitHub para escribir una especificación, un plan y tareas antes de que un agente escriba código.
  • OpenSpec - Desarrollo guiado por especificaciones en el que cada cambio se propone, revisa y archiva como archivos del repositorio.
  • BMAD Method - Roles ágiles interpretados por agentes, desde analista y arquitecto hasta desarrollador y QA.
  • Agent OS - Escribe los estándares y especificaciones de un código en archivos con los que trabajan los agentes.
  • Superpowers - Una biblioteca de skills que guía a un agente por la lluvia de ideas, la planificación, el desarrollo guiado por pruebas y la revisión.

Seguimiento de tareas para agentes

  • Task Master - Convierte un documento de producto en tareas dependientes que un agente resuelve una a una.
  • Beads - Un gestor de incidencias dentro del repositorio, pensado para que los agentes abran, tomen y cierren trabajo.
  • Backlog.md - Un tablero de tareas en Markdown dentro de Git que comparten personas y agentes.

Prompts, skills y subagentes reutilizables

  • Awesome Copilot - Instrucciones, prompts, agentes y skills de la comunidad para GitHub Copilot.
  • Awesome CursorRules - Archivos de reglas para Cursor, ordenados por lenguaje y framework.
  • Agents by wshobson - Plugins, subagentes y comandos escritos una vez en Markdown y generados para varios agentes de programación.
  • Awesome Claude Code Subagents - Más de cien definiciones de subagentes especializados.
  • Claude Cookbooks - Cuadernos con patrones, incluidos flujos de agentes y uso de herramientas.

Revisión y aprobación

  • HumanLayer - Flujos para agentes de programación en problemas difíciles, con pasos de investigación, plan e implementación que revisa una persona.
  • PR-Agent - Un revisor de código abierto que comenta pull requests, como segunda pasada junto a la revisión de una persona.
  • Claude Code Security Review - Una GitHub Action que revisa cada cambio en busca de problemas de seguridad.

Agentes en paralelo

  • Claude Squad - Varios agentes de terminal a la vez, cada uno en su propio worktree de Git, gestionados desde una terminal.
  • Container Use - Un contenedor y una rama por agente, para que varios trabajen en un proyecto sin chocar.
  • Crystal - Una app de escritorio para sesiones de agentes en paralelo en worktrees, para comparar enfoques (ahora Nimbalyst).
  • Ruflo - Coordina enjambres de agentes con memoria compartida en torno a Claude Code y otros agentes.

Agentes en CI

  • Claude Code Action - Ejecuta Claude Code desde issues y pull requests en GitHub Actions.
  • OpenHands - Una plataforma abierta para agentes de programación que funciona en local, en la nube o sin interfaz en CI.
  • SWE-agent - Toma un issue de GitHub e intenta resolverlo con el modelo de lenguaje que elijas.

Frameworks con una persona en el circuito

  • LangGraph - Agentes como grafos que pueden pausarse para una persona y reanudar desde un estado guardado.
  • OpenAI Agents SDK - Un framework ligero para flujos multiagente con traspasos y salvaguardas.
  • CrewAI - Orquesta agentes que interpretan roles, con tareas que pueden pedir información a una persona.
