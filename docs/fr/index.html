Des façons reproductibles de travailler avec des agents de code IA : plans et spécifications, files de tâches, prompts et skills réutilisables, points de relecture et étapes qui attendent une personne.

À la une : Aubergine - Des terminaux sur un canevas dans le navigateur, avec des workflows dont les étapes peuvent attendre l’accord du propriétaire, une file de tâches et des brouillons relus avant usage. (Maintenu par les auteurs de cette liste.)

Cette liste porte sur le travail autour d’un agent plutôt que sur l’agent lui-même : comment une tâche est rédigée, découpée, transmise, vérifiée et validée. Les entrées sont open source ou librement consultables, sauf mention contraire.

Principes et guides

  • Construire des agents efficaces - Les patterns d’Anthropic pour les workflows et les agents, de l’enchaînement de prompts à l’orchestrateur et ses exécutants.
  • Bonnes pratiques de Claude Code - Explorer, planifier, coder et committer, avec des points de contrôle où une personne peut intervenir.
  • 12-Factor Agents - Des principes pour des agents assez fiables pour la production, dont le fait de contacter une personne via un appel d’outil.

Fichiers d’instructions et standards

  • AGENTS.md - Un simple fichier Markdown dans un dépôt qui explique à n’importe quel agent de code comment compiler, tester et suivre les conventions.
  • Model Context Protocol - Le protocole ouvert pour donner outils et contexte aux agents, avec sa spécification.
  • Agent Skills - Des dossiers d’instructions et de scripts qu’un agent charge quand une tâche le demande.
  • Claude Code hooks - Des commandes exécutées à des moments fixes du tour d’un agent, pour des vérifications qui ne doivent pas dépendre de la mémoire du modèle.

Planification et développement piloté par les spécifications

  • Spec Kit - La boîte à outils de GitHub pour rédiger une spécification, un plan et des tâches avant qu’un agent écrive du code.
  • OpenSpec - Développement piloté par les spécifications où chaque changement est proposé, relu et archivé sous forme de fichiers dans le dépôt.
  • BMAD Method - Des rôles agiles tenus par des agents, de l’analyste et l’architecte au développeur et au testeur.
  • Agent OS - Consigne les standards et spécifications d’une base de code dans des fichiers sur lesquels travaillent les agents.
  • Superpowers - Une bibliothèque de skills qui guide un agent à travers le brainstorming, la planification, le TDD et la relecture.

Suivi des tâches pour agents

  • Task Master - Transforme un document produit en tâches dépendantes qu’un agent traite une par une.
  • Beads - Un gestionnaire de tickets dans le dépôt, conçu pour que les agents créent, prennent et clôturent le travail.
  • Backlog.md - Un tableau de tâches en Markdown dans Git, partagé par les personnes et les agents.

Prompts, skills et sous-agents réutilisables

  • Awesome Copilot - Instructions, prompts, agents et skills de la communauté pour GitHub Copilot.
  • Awesome CursorRules - Fichiers de règles pour Cursor, classés par langage et framework.
  • Agents by wshobson - Plugins, sous-agents et commandes écrits une fois en Markdown et générés pour plusieurs agents de code.
  • Awesome Claude Code Subagents - Plus d’une centaine de définitions de sous-agents spécialisés.
  • Claude Cookbooks - Des notebooks de patterns, dont des workflows d’agents et l’usage d’outils.

Relecture et validation

  • HumanLayer - Des workflows pour agents de code sur des problèmes difficiles, avec des étapes de recherche, de plan et d’implémentation relues par une personne.
  • PR-Agent - Un relecteur open source qui commente les pull requests, en complément de la relecture humaine.
  • Claude Code Security Review - Une GitHub Action qui examine chaque changement à la recherche de problèmes de sécurité.

Plusieurs agents côte à côte

  • Claude Squad - Plusieurs agents en terminal à la fois, chacun dans son propre worktree Git, pilotés depuis un seul terminal.
  • Container Use - Un conteneur et une branche par agent, pour que plusieurs travaillent sur un projet sans se marcher dessus.
  • Crystal - Une application de bureau pour des sessions d’agents en parallèle dans des worktrees, afin de comparer les approches (désormais Nimbalyst).
  • Ruflo - Coordonne des essaims d’agents à mémoire partagée autour de Claude Code et d’autres agents.

Agents en CI

  • Claude Code Action - Lance Claude Code depuis les issues et pull requests dans GitHub Actions.
  • OpenHands - Une plateforme ouverte pour agents de code, en local, dans le cloud ou sans interface en CI.
  • SWE-agent - Prend une issue GitHub et tente de la corriger, avec le modèle de langage de votre choix.

Frameworks avec une personne dans la boucle

  • LangGraph - Des agents sous forme de graphes qui peuvent se mettre en pause pour une personne et reprendre depuis un état sauvegardé.
  • OpenAI Agents SDK - Un petit framework pour workflows multi-agents avec passages de relais et garde-fous.
  • CrewAI - Orchestre des agents qui jouent des rôles, avec des tâches pouvant demander l’avis d’une personne.
